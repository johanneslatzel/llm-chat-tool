# Examples

Complete TypeScript programs for this package. Install it once:

```bash
npm install @johannes.latzel/llm-chat-tool
```

## Scenarios

- [Executing a tool](executing-tools.md) - call an HTTP-backed weather tool with arguments
- [Typed tools](typed-tools.md) - nested objects, arrays, hidden aliases and multiple results
- [Tool packages](tool-packages.md) - group tools and read their tutorial text
- [Timed tools](timed-tools.md) - bound an execution with a timeout and cancellation signal
